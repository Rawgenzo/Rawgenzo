# AI の道具と GUI の機能の対応

Rawgenzo アプリの画面でできることのうち、どれを AI の道具(MCP の tools)にしたか、まだしていないか、
してはいけないかの一覧。2026-10-16 時点。道具の整備はここで一旦止めている。

プロセスと通信の全体像は [ai-mcp-architecture.md](ai-mcp-architecture.md)、検討の経緯は [ai-agent-architecture.md](ai-agent-architecture.md)。
一覧は、画面のボタン・スイッチ・選択肢・メニューをコードから拾って作った。右クリックのメニューなど、細かいものは漏れているかもしれない。

## 道具にしたもの

### 調整パネル(現像設定。サイドカーに保存され、AI の undo で取り消せる)

| GUI の機能 | 場所 | 道具 |
|---|---|---|
| 露出・コントラスト・色温度・色かぶり | 基本 | `adjust`(changes で値を指定、deltas で今の値に足す) |
| HDR の強さ・ハイライト回復・シャドウ持ち上げ | HDR | `adjust`。明るさや白飛びを目標に合わせるときは `solve_exposure` |
| HDR ディスプレイ向けに出力 | HDR | `set_hdr_output`(効くのは書き出しだけ) |
| 彩度・自然な彩度 | 色 | `adjust` |
| シャープネス・輝度ノイズ除去・色ノイズ除去 | ディテール | `adjust` |
| 周辺減光・歪曲・倍率色収差、カメラの設定に戻す | レンズ補正 | `set_lens_correction` |
| クロップ枠・比率・傾き補正・クロップを解除 | クロップ | `set_crop`。枠は `get_preview` の `ignore_crop` で切り抜く前の全体を見て決める |
| ルックの選択・強さ | ルック | `list_looks`・`set_look`。`get_preview` の `look` で保存せずに試せる |
| すべて初期値に戻す | 調整パネルの上 | `reset_settings`(keep で切り抜き・ルックを残せる) |
| 各スライダーの ↶(初期値に戻す) | 各スライダー | `adjust` の changes に null |

### 見るためのもの(読むだけ)

| GUI でしていること | 道具 |
|---|---|
| アプリで開いている写真・フォルダ・表示倍率を見る | `get_app_state` |
| ファイル一覧・撮影情報を見る | `list_photos`(folder でほかのフォルダも見られる)・`get_photo` |
| プレビューを見る | `get_preview`(縮小 JPEG。画像はトークンを多く使う)・`get_stats`(数値。安い) |
| 一部を拡大して見る | `get_preview` の `region`(等倍まで) |
| クロップ枠・構図ガイドを重ねて見る | `get_preview` の `show_crop_frame`・`guide`(枠の中にガイドを描く) |
| (GUI には無い) 取り消し・操作の履歴 | `undo`・`recent_operations`(操作面の汎用の道具) |
| (GUI には無い) 傾きの手がかり | `estimate_tilt`(番号付きの直線と人物の目・肩の線。AI が基準の線を選ぶと角度を返す) |

## まだ道具にしていないもの

必要になったら着手する。上ほど役に立つ。

| GUI の機能 | 場所 | 道具にするときの注意 |
|---|---|---|
| 書き出し・保存先を選んで書き出し | ファイルメニュー(⌘E / ⇧⌘E) | ファイルを書く操作なので、影響の段階は writeFiles(人の確認が要る)になる。この段階の道具は初めてなので、確認の出し方から決める。CLI(`rawdev develop`)では今もできる |
| 写真を開く・フォルダを開く | 一覧での選択・「フォルダを開く…」(⌘O) | AI がアプリの表示を変える初めての道具になる。人が操作している最中に表示が勝手に変わらないよう、決め事が要る |
| 表示倍率(ウインドウに合わせる・実際のサイズ・拡大・縮小) | 表示メニュー | 表示だけなので急がない。「顔を等倍で見せて」などに使える |
| 構図ガイドをアプリの画面に出す(表示、種類、反転・向き、線の太さ) | 表示メニュー・ツールバー | 人の画面の表示。AI が自分で見るためのガイドは `get_preview` の `guide` で描ける |
| 収まる最大まで広げる | クロップ | 傾けた後に収まる最大の枠は AI には計算しにくい。`set_crop` の指定の 1 つとして足せる |

## 道具にしなくてよいもの

| GUI の機能 | 理由 |
|---|---|
| クロップ枠の調整モード(「枠を調整する」) | 人がドラッグするための状態。AI は `set_crop` で直接枠を決める |
| サムネイルの表示と大きさ | 人の見やすさの設定 |
| Finder で表示 | 人が Finder で見るための操作 |
| Rawgenzo について | 情報の表示だけ |

## 道具にしてはいけないもの

| GUI の機能 | 理由 |
|---|---|
| **AI からの操作を受け付ける**(設定・一般) | AI が自分で受け付けをオンにできると、人が AI を止める手段が無くなる。この設定は人だけが変える |
| 書き出し設定(既定のフォルダ・形式・色空間・ファイル名の決まり・同じ名前のとき・連番) | 写真ごとではなく、持続するアプリの設定。人が決めるもの。AI が変えると、後の書き出しが人の知らないうちに変わる |
| 設定ファイルの「ファイルから読み直す」 | 同上(アプリの設定を入れ替える操作) |

## 道具を足すときに合わせて直すところ

道具を足すたびに、次も直す。漏らすと、2026-10-16 のように読むだけの道具が「写真を変更しました」と知らされたりする。

- `RawgenzoTools.instructions`(AI への説明): どんな指示にこの道具を使うか
- テスト: 道具の並び(`testToolsAreRegisteredInStableOrder`)と、道具そのもののテスト
- アプリの知らせの文言: `EditorModel.noteAgentCall`(文言を登録しない道具は「〈道具名〉を使いました」になる)
- アプリの強調: 変えた項目を `EditorModel.applyAgentSettings` で見分け、調整パネルの欄に `AgentHighlight` を付ける
- 写真を 1 枚指す道具なら、結果を `warned` で包む(アプリで開いている写真と違えば知らせる)
- 文書: この一覧、`README.md`、`CLAUDE.md`、`ai-mcp-architecture.md` の主なソース
- 道具の一覧は会話のたびに AI に送られる。説明は短くし、同じ説明を複数の道具に載せない
  (2026-10-16 時点で 15 個、約 27.7 KB)
